# Third-Party-Patcher-Pages

Source for the [Third Party Patcher](https://github.com/gilburns/Third-Party-Patcher) landing page, published via GitHub Pages at [thirdpartypatcher.org](https://thirdpartypatcher.org).

Plain static HTML/CSS/JS — no build step. Edit `index.html` and `assets/css/style.css`, then push to `main` to deploy.

Screenshots in `assets/img/` are sourced from the [project wiki](https://github.com/gilburns/Third-Party-Patcher/wiki).
